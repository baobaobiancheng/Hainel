# 医疗知识库数据导入指南

## 一、当前数据现状

**`backend/data/` 目录现在是空的**，没有任何知识数据文件。系统目前在以下两个层面分别处理知识库：

| 层面 | 实现方式 | 数据状态 |
|------|---------|---------|
| HTTP API（医生端前端） | `app/api/v1/knowledge.py` 内置静态数据 | ✅ 已有 10 条示例条目 |
| AI 智能体 RAG 检索 | Milvus Lite 向量库（`data/milvus.db`） | ❌ 空库，需要导入 |

## 二、数据从哪里来

### 2.1 推荐数据源

#### 方案 A：CMeKG（中文医学知识图谱）⭐ 推荐
- **简介**：国内最大的中文医学知识图谱，覆盖 1 万多种疾病、3 万多种症状、1 万多种药物
- **获取方式**：
  - GitHub 工具库：https://github.com/king-yyf/CMeKG_tools
  - 官方网站：http://cmekg.pcl.ac.cn/
  - 数据集需注册申请，审核后提供下载
- **数据格式**：JSON 三元组（实体-关系-实体）
- **适合用途**：疾病-症状关联、药物-适应症关联、知识图谱可视化

#### 方案 B：中文医学 NLP 公开数据集
| 数据集 | 内容 | 下载地址 |
|--------|------|---------|
| CHIP 系列 | 临床实体识别、关系抽取 | https://www.cips-chip.org.cn/ |
| CCKS 医学数据集 | 医学命名实体、问答 | https://www.biendata.xyz/competition/ccks |
| 中文医学问答 | 疾病百科、问答对 | https://github.com/Toyhom/Chinese-medical-dialogue-data |
| 医学百科全书 | 疾病详情、治疗方案 | https://github.com/GanjinZero/CMedED |

#### 方案 C：临床指南 PDF（手动整理）
- 中华医学会各专业委员会官网均提供免费 PDF 下载
- 中国医脉通：https://www.medlive.cn/
- 需要手动提取文本后整理成结构化 JSON

#### 方案 D：直接使用项目内置静态数据（最简单）
项目 `app/api/v1/knowledge.py` 中已经内置了 10 条高质量条目（高血压、糖尿病、冠心病、COPD、脑卒中、发热、胸痛、阿司匹林、二甲双胍、氨氯地平），可以直接作为种子数据导入 Milvus Lite，无需外部数据。

## 三、数据格式规范

每条知识条目需符合以下 JSON 格式：

```json
{
  "id": "disease_001",
  "title": "高血压",
  "type": "disease",
  "category": "内科",
  "description": "一句话简介（50字以内）",
  "content": "完整的正文内容，支持HTML格式",
  "tags": ["心血管", "慢性病", "降压药"],
  "related_entities": ["冠心病", "脑卒中", "氨氯地平"]
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 全局唯一，建议用 `disease_001` 格式 |
| `title` | string | ✅ | 条目标题 |
| `type` | string | ✅ | `disease`（疾病）/ `symptom`（症状）/ `drug`（药物） |
| `category` | string | ✅ | 科室分类：内科/外科/神经科/呼吸科/药学/症状 等 |
| `description` | string | ✅ | 用于列表展示的简介 |
| `content` | string | ✅ | 完整正文，供 AI 检索用，可含 HTML 标签 |
| `tags` | array | - | 关键词标签，用于过滤和知识图谱 |
| `related_entities` | array | - | 相关实体名称，用于知识图谱连线 |

## 五、导入操作步骤

### 步骤 1：确认环境

```bash
# 进入 backend 目录
cd backend

# 确认虚拟环境已激活
.venv\Scripts\activate   # Windows
# 或
source .venv/bin/activate  # macOS/Linux

# 确认 .env 中已填写 DashScope API Key
# LLM_API_KEY=sk-你的真实Key
```

### 步骤 2：准备数据文件

**方法 A（推荐）：直接使用内置静态数据**

无需额外文件，跳到步骤 3 执行以下命令：

```bash
uv run python scripts/init_knowledge.py --source builtin
```

**方法 B：导入自己的 JSON 文件**

将数据文件放到 `backend/data/knowledge/` 目录下，然后执行：

```bash
uv run python scripts/init_knowledge.py --source file --path data/knowledge/diseases.json
```

def load_from_file(path: str) -> list:
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def main():
    parser = argparse.ArgumentParser(description="知识库数据导入工具")
    parser.add_argument("--source", choices=["builtin", "file"], default="builtin",
                        help="数据来源：builtin（内置）或 file（文件）")
    parser.add_argument("--path", type=str, default=None,
                        help="JSON 文件路径（--source file 时使用）")
    parser.add_argument("--clear", action="store_true",
                        help="导入前清空现有数据（谨慎使用）")
    args = parser.parse_args()

    if args.source == "file":
        if not args.path:
            print("错误：使用 --source file 时必须指定 --path 参数")
            sys.exit(1)
        print(f"从文件加载数据: {args.path}")
        raw_data = load_from_file(args.path)
    else:
        print("使用内置种子数据")
        raw_data = BUILTIN_DATA

    print(f"共 {len(raw_data)} 条数据待导入")
    print("正在初始化知识库（首次运行会调用 DashScope Embedding API，请确保网络畅通且 API Key 已配置）...")

    kb = get_knowledge_base()

    items = []
    for d in raw_data:
        items.append(KnowledgeItem(
            id=d["id"],
            title=d["title"],
            content=d.get("content", d.get("description", "")),
            category=d.get("category"),
            tags=d.get("tags", []),
            metadata={
                k: v for k, v in d.items()
                if k not in ("id", "title", "content", "category", "tags")
            },
        ))

    success = kb.add_batch(items)

    if success:
        print(f"✅ 导入完成！共写入 {len(items)} 条知识条目到 Milvus Lite")
        print(f"   数据库文件：backend/data/milvus.db")
    else:
        print("❌ 导入失败，请检查日志输出")
        sys.exit(1)


if __name__ == "__main__":
    main()

## 七、注意事项

1. **API 费用**：导入 100 条数据大约调用 DashScope Embedding API 100 次，费用极低（约 0.01 元）
2. **数据持久化**：`data/milvus.db` 不要删除，删除后需重新导入
3. **版本控制**：`data/milvus.db` 不要提交到 git（应在 `.gitignore` 中排除）
4. **增量更新**：已导入的数据无需重新导入，直接追加即可（Milvus Lite 不会自动去重，重复导入会产生重复向量，建议维护好源数据文件避免重复）
