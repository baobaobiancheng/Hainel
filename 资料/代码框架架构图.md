## 3. 数据流架构

### 3.1 咨询请求流程

```
患者输入主诉
    ↓
[API层] POST /api/conversations/{id}/messages
    ↓
[服务层] conversation_service.create_message()
    ↓
[智能体系统] moderator_agent.process()
    ↓
[复杂度评估] complexity_evaluator.evaluate()
    ├─→ 低复杂度 → PCC模式
    ├─→ 中复杂度 → MDT模式
    └─→ 高复杂度 → ICT模式
    ↓
[智能体处理]
    ├─ PCC: pcc_agent.process() → 直接回答
    ├─ MDT: mdt_team.discuss() → 共识达成 → 综合结论
    └─ ICT: ict_team.process() → 分阶段处理 → 综合报告
    ↓
[病历生成] medical_record_service.generate_draft()
    ↓
[推送给医生] WebSocket推送 / API通知
    ↓
医生审核确认
```

### 3.2 训练流程

```
[患者模拟] patient_agent.generate_case()
    ↓
[医生智能体] doctor_agent.interview()
    ↓
[多轮对话] 动态症状释放
    ↓
[奖励评估] reward_calculator.calculate()
    ├─ 诊断准确性奖励
    ├─ 信息获取效率奖励
    ├─ 协作效率奖励
    └─ 规范遵循奖励
    ↓
[强化学习] rl_trainer.train()
    ↓
[模型更新] 更新智能体策略
    ↓
[性能监控] performance_monitor.track()
```

## 6. 关键设计模式

### 6.1 策略模式
- **复杂度评估策略**：可切换不同的评估算法
- **概率模型策略**：贝叶斯网络、ML分类器、LLM推理
- **通信策略**：同步/异步通信切换

### 6.2 工厂模式
- **智能体工厂**：根据类型创建不同智能体
- **团队工厂**：根据复杂度创建不同团队结构

### 6.3 观察者模式
- **训练监控**：观察训练过程，记录指标
- **性能监控**：观察系统性能，触发告警

### 6.4 模板方法模式
- **智能体基类**：定义处理流程模板，子类实现具体步骤
- **专科智能体基类**：定义专科处理模板
