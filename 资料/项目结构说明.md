# 项目结构说明

## 📁 目录结构概览

根据代码框架设计，已创建完整的项目文件夹结构。以下是各目录的说明：

## 🗂️ 后端目录（backend/）

### 核心应用目录（app/）

- **api/** - API路由层
  - `v1/` - API版本1的路由文件
  - `websocket.py` - WebSocket连接处理

- **core/** - 核心功能模块
  - `security.py` - 安全认证（JWT、密码加密）
  - `permissions.py` - 权限管理（RBAC）
  - `exceptions.py` - 自定义异常
  - `middleware.py` - 中间件（日志、CORS等）

- **models/** - 数据库模型（SQLAlchemy）
  - `base.py` - 基础模型类
  - `user.py` - 用户模型
  - `conversation.py` - 会话模型
  - `message.py` - 消息模型
  - `medical_record.py` - 病历模型
  - 等等...

- **schemas/** - Pydantic模式（请求/响应验证）
  - 对应models目录下的各个Schema定义

- **services/** - 业务服务层
  - `user_service.py` - 用户服务
  - `conversation_service.py` - 会话服务
  - `medical_record_service.py` - 病历服务
  - 等等...

- **agents/** - 多智能体系统（核心模块）
  - `base/` - 智能体基类和接口定义
  - `moderator/` - 调节器代理（复杂度评估、路由）
  - `pcc/` - PCC模式（低复杂度，单个智能体）
  - `mdt/` - MDT模式（中复杂度，3-5个智能体）
  - `ict/` - ICT模式（高复杂度，5-7个智能体）
  - `specialty/` - 专科智能体（CardioMind等）
  - `patient_simulator/` - 患者模拟智能体
  - `reminder/` - 提醒服务智能体
  - `orchestrator/` - 智能体编排器
  - `evaluation/` - 评估与优化系统

- **nlp/** - NLP处理模块
  - `ner.py` - 命名实体识别
  - `relation_extraction.py` - 关系抽取
  - `medical_record_parser.py` - 病历解析器
  - 等等...

- **ml/** - 机器学习模块
  - `probability_models/` - 概率模型（贝叶斯网络、ML分类器、LLM推理）
  - `diagnosis_suggester.py` - 诊断建议生成器
  - 等等...

- **knowledge/** - 知识库模块
  - `cmekg.py` - CMeKG知识库接口
  - `clinical_guidelines.py` - 临床指南知识库
  - 等等...

- **ai/** - AI模型服务层
  - `llm/` - 大语言模型服务（Qwen、ChatGLM等）
  - `ocr/` - OCR服务（PaddleOCR、百度OCR）
  - `embeddings/` - 向量嵌入服务

- **database/** - 数据库访问层
  - `base.py` - 数据库基类
  - `session.py` - 数据库会话管理
  - `redis_client.py` - Redis客户端

- **utils/** - 工具函数
  - `logger.py` - 日志工具
  - `cache.py` - 缓存工具
  - 等等...

- **tasks/** - 异步任务（Celery）
  - `celery_app.py` - Celery应用配置
  - `reminder_tasks.py` - 提醒任务
  - 等等...

### 其他后端目录

- **alembic/** - 数据库迁移工具
  - `versions/` - 迁移脚本目录
  - `env.py` - Alembic环境配置

- **tests/** - 测试代码
  - `unit/` - 单元测试
  - `integration/` - 集成测试
  - `e2e/` - 端到端测试
  - `conftest.py` - pytest配置

- **scripts/** - 脚本工具
  - `init_db.py` - 数据库初始化
  - `seed_data.py` - 种子数据
  - `train_agents.py` - 智能体训练脚本

## 🚀 下一步

1. **配置环境**
   - 复制 `backend/.env.example` 为 `backend/.env`
   - 修改数据库和API密钥配置

2. **安装依赖**
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. **初始化数据库**
   ```bash
   alembic init alembic  # 如果还没有初始化
   alembic upgrade head
   ```

4. **开始开发**
   - 按照代码框架设计文档实现各个模块
   - 参考 `代码框架设计.md` 了解详细设计
