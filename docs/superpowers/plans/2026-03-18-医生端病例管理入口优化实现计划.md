# 医生端病例管理入口优化实现计划

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在患者列表页面增加"新建病历"入口，医生可直接为指定患者创建病历，无需手动输入患者ID。

**Architecture:**
- 在 Patients.vue 操作列增加"新建病历"按钮
- 按钮点击后检查患者是否有病历，有则跳转病历页面并筛选，无则打开新建病历弹窗
- Records.vue 移除手动 patient_id 输入，改为从路由参数获取

**Tech Stack:** Vue 3 + Ant Design Vue

- [ ] **Step 3: 添加 handleCreateRecord 函数**

```javascript
const handleCreateRecord = async (patientId) => {
  // 检查该患者是否有病历
  try {
    const response = await getMedicalRecords({ patient_id: patientId, page: 1, page_size: 1 })
    const hasRecords = response.data?.total > 0

    if (hasRecords) {
      // 已有病历，跳转到病历页面并筛选
      router.push({
        path: '/records',
        query: { patient_id: patientId, alert: 'has_records' }
      })
    } else {
      // 无病历，打开新建病历弹窗
      router.push({ path: '/records', query: { create_for_patient: patientId } })
    }
  } catch (error) {
    message.error('检查病历失败')
  }
}
```

```javascript
// 在 script 中添加
const createFromPatient = ref(false)
const createPatientName = ref('')

onMounted(() => {
  loadRecords()

  // 检查是否有新建病历的路由参数
  const createForPatient = route.query.create_for_patient
  if (createForPatient) {
    createForm.value.patient_id = createForPatient
    createFromPatient.value = true
    // 可以在这里查询患者姓名
    showCreateModal()
  }

  // 检查是否有筛选患者的路由参数
  const filterPatientId = route.query.patient_id
  if (filterPatientId) {
    filterPatient.value = filterPatientId
    loadRecords()
  }

  // 路由参数处理
  const recordId = route.query.id
  if (recordId) viewDetail(parseInt(recordId))
  if (route.query.action === 'review' && recordId) showReviewModal({ id: parseInt(recordId) })
})
```
