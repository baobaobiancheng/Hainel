# 患者端状态消息气泡显示实现计划

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将患者端咨询页面的状态提示从顶部状态栏和 wx.showLoading 加载框改为对话气泡形式

**Architecture:** 复用现有消息列表结构，使用 message_type: 'status' 区分状态消息，使用 role: 'assistant' 复用左侧气泡样式

**Tech Stack:** 微信小程序 (WXML, WXSS, JavaScript)

- [ ] **Step 2: 添加 handleStatusUpdate 方法**

在 `handleWsMessage` 方法结束后（约第210行），添加新方法:
```javascript
  // 处理状态更新消息
  handleStatusUpdate(data) {
    // 使用浅拷贝创建新数组，避免直接修改原始数据
    const statusMessages = [...this.data.messages]
    const existingStatusIndex = statusMessages.findIndex(
      m => m.message_type === 'status'
    )

    const statusMsg = {
      id: `status-${Date.now()}-${Math.random().toString(36).substr(2, 9)}`,
      role: 'assistant',
      message_type: 'status',
      status: data.status,
      content: data.message,
      agent_name: '系统',
      timestamp: new Date().toISOString()
    }

    if (existingStatusIndex >= 0) {
      // 更新现有状态消息
      statusMessages[existingStatusIndex] = statusMsg
    } else {
      // 添加新状态消息
      statusMessages.push(statusMsg)
    }

    this.setData({ messages: statusMessages })
    this.scrollToBottom()

    // 诊断完成时刷新消息列表（清除状态消息，显示真实AI回复）
    if (data.status === 'completed') {
      setTimeout(() => {
        this.loadMessages()
      }, 2000)
    }
  },
```
